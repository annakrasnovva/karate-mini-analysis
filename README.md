# Анализ набора и численности клуба карате SSK

Самостоятельный аналитический проект, 2025.

## Цель
Исследовать состав участников клуба в разных городах, источники привлечения, возраст новичков и запросы родителей для улучшения сбора данных и планирования набора.

## Данные
На начало 2025 года клуб насчитывал 98 занимающихся в трёх городах: Коряжма — 33, Котлас — 27, Северодвинск — 38. Опрос прошли 59 родителей (60,2%).

## Выполненная работа
- Анализ распределения по городу, году и возрасту начала занятий.
- Сопоставление источников привлечения и запросов родителей.
- Изучение исторической динамики численности в двух городах.
- Подготовка презентации с выводами и рекомендациями по учёту новичков.

## Наблюдения
В Коряжме и Котласе важным каналом привлечения являются рекомендации знакомых. Для объективной оценки удержания необходимы сведения об ушедших участниках.

## Ограничения
Результаты опроса не следует автоматически распространять на всех участников клуба: ответили не все родители, доли ответивших отличаются между городами. Причины изменений численности и эффективность рекламы по текущим данным не доказаны. Необходимо добавить методику расчётов и код или таблицу для воспроизведения исследования.
